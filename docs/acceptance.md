## D1 場景矩陣

四套工具（CASP SR-RCT、CASP SR-OBS、RoB 2、GRADE）各跑一輪，預期結果：

1. 留一題未答 → 進度為 N−1 / N，不顯示「對照參考答案」
2. 重新整理 → 進度與作答保留
3. 完整作答 → 出現「對照參考答案」，展開後顯示參考理由與出處
4. 展開後修改答案 → 該題比對即時變為「不同」，導覽列標出有差異的步驟
5. 匯出 → 合法 JSON、`toolId` 正確
6. 指導者匯入 → 逐題並排比對；`contentHash` 被竄改的檔案被拒並顯示欄位與原因
7. 作答後**立即**重新整理／切換工具 → 作答不遺失；作答後立即按「重設」→ 清空且不被寫回

## 驗收中發現並修正的缺陷

| 缺陷 | 影響 | 修正 |
|---|---|---|
| 自動保存延遲 250 ms，離開頁面前未寫入 | 作答後 250 ms 內重新整理或關閉分頁，最後的作答遺失 | `pagehide`／`visibilitychange` 時立即寫入（`js/app.js`） |
| 切換工具或文獻時，前一份評讀延遲中的變更被寫進新開的評讀 | 切換前最後的作答遺失 | 開啟評讀前先寫入；按「重設」時先取消延遲寫入，避免舊作答被寫回 |
| 報告的欄位名稱欄以 `max-content` 排版，且長網址無法斷行 | 360 px 下 GRADE 報告的值被擠成一字一行，對話框內出現水平捲動 | 名稱欄上限 40%，報告內長字串可斷行（`css/styles.css`） |
